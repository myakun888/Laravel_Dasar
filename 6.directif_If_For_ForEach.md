# directif

### directif For

directif for di blade sebagai berikut

```blade.php

@for ($i = 0; $i < $10; $i++)
  <h2>nilai nya adalah {{$i}}</h2>
@endfor
```

#### directif if

untuk directif if sebagai berikut

```blade.php


<!-- kondisi -->

  @if ($n = 10)



  <h2> nilai anda {{$n}}</h2>


  @endif



```

#### directif if-else

```blade.php

<!-- kondisi -->
  @if ($n >= 8;)

  <h2> nilai anda {{$n}}</h2>
  <h2>sangat memuaskan</h2>

<!-- else, atau selain itu -->
  @else

  <h2>nilai anda memuaskan</h2>

  @endif


```

#### directif forEach

```blade.php


  @php

  $kitab_suci = [
  "Al-Quran","Injil","Taurat" ,"Zabur"
];
  @endphp

  @foreach ($kitab_suci as $kitab)

  kitab suci {{$kitab}}
  @endforeach

```
