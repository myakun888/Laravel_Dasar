# Yield dan Section

## Yield

yield adalah tempat kosong yang kita tempa untuk di isi nilai dari view child .
atau bisa kita anggap sebagai placeholder.

contoh

`layout.blade.php`

```blade.php

<h1> selamat Datang Di Home </h1>

@yield('namaAnda');



```

`child.blade.php`

```blade.php


// cara pertama
@yield('namaAnda', 'Muhammad Fajrin Saputra');


// cara kedua

@section('namaAnda')

'Muhammad Fajrin Saputra'

@endSection


```

### Section

section di blade kita bisa asumsikan segagai _bagian_, kita bisa membuat section di parent lalu kita gunakan di child nya

`fileA.blade.php`

```blade.php

<div>

<h1> Selamat Datang </h1>


@section('namaAnda')
@show
</div>

```

`fileB.blade.php`

```blade.php


@seciton('namaAnda')

Muhammad Fajrin Saputra
@endSection

```

pada contoh di atas maka nilai dari child akan menimpa yang ada di fileA, di dalam section'namaAnda'

sekilas mirip seperti `yield`, untuk kondisi seperti ini lebih baik gunakan yield, namun section dapat mengirimkan nilai di parent, artinya kita bisa bawa nilai / value nya, dan di tambah dengan value yang kita kirim , ini dengan menggunkaan @parent di child nya

> note: jadi pasangan nya `@section` di tutup dengan `@show`,
> lalu di child nya `@section` di tutup dengan `@endSection`, jika ingin menampilkan isi section dari parent kita tambahkan `@parent` di dalam nya child nya menjadi  
> `@section` `@parent` `@endSection`

`fileA.blade.php`

```blade.php

<div>

<h1> Selamat Datang </h1>


@section('namaAnda')
apa kabar

@show
</div>

```

`fileB.blade.php`

```blade.php


@seciton('namaAnda')
@parent

Muhammad Fajrin Saputra
@endSection

```

ini hasil nya jika kita isi, maka

```blade.php

apa kabar
Muhammad Fajrin
```

jika kita tidak isi maka hanya tampil value dari parent saja

```blade.php

apa kabar
```
