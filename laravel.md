# Laravel

adalah suatu framework dari bahasa pemrograman PHP, yang menggunakan konsep MVC.

untuk dapat mengerti laravel dengan cepat, ada baiknya kita harus mengerti php oop (object oriented programming), karena laravel menggunakan konsep oop juga.

dengan adanya framework ini dapat memudahkan kita dalam membuat aplikasi , dan dengan aturan yang di buat oleh framework ini.

kita akan lebih cepat , seperti membuat route, auth, atau pun ada juga beberapa template / builder sepert inertia, untuk frontend nya, untuk database nya sudah di sediakan ORM dari php nya dan lainya segala kemudahan yang di berikan laravel untuk membantu kita membuat aplikasi.
