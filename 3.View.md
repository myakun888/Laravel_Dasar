# View

View merupakan komponen V dalam arsitektur MVC (MODEL-VIEW-CONTROLLER). jika controller bertugas memperoses logika bisnis dan menyiapakan data. maka view bertugas menerima dan menyajikan data tersebut dan menyusun tampilan antarmuka (frondendt) dengan hmtl/css/js yang dapa di lihat toleh pengguna.

## lokasi dan format berkas view

secara default lokasi file view pada laravel berada di path

`resources/views/`

```cmd


   │resources
   ├── css
   │   └── app.css
   ├── js
   │   ├── app.js
   │   └── bootstrap.js
   └── views
       └── welcome.blade.php
```

### mebuat view

**format penulisan**
jika membuat file `namafile.blade.php`

> note: blade adalah extension untuk file view secara default pada laravel

jika ingin cara mengenerate lewat terminal bisa mengguunakna perintah

`php aritsan make:view namaFile`

contoh

`php artisan make:viw profile`;

### memanggil file view

```php


route::get('/home', function (){

return view('welcome');
})

```

> note: cukup tulis nama nya tidak perlu menulis .blade.php

jika di dalam subfolder seperti `views/data/profile.blade.php` maka cara menulis nya menggunakan tanda baca titik(.) untuk memasuk ke subfolder

```php

view ('data.profile');



```
