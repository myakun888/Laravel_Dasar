# Directif di Blade

pada blade kita sudah tau, kelebihan nya,kita dapat dengan mudah menulis code pemrograman php di dalam nya
menggunakan directif.

`@php ` dan di tutup dengan `@endPhp`;

di dalam nya kita dapat menulis kode php pemrograman php seperti biasa.

```blade.php


@php

$tuhan = "ALLAH";
@endPhp


<div>



</div>
```

selain itu masih banyak directif lain yang dapat kita gunakan di blade dan bisa berdampingan dengan HTML, dan ini jauh lebih ringkas di banding pada file php biasa

diantara nya

- directif if
- directif forEach
- directif For
- directif lainya

## menampilkan data pada blade

jika di php biasa, kita cara menulis nya

```php

<?php
$TUHAN = "ALLAH";
?>

<!DOCTYPE html>
<html lang="">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title></title>
  <link href="css/style.css" rel="stylesheet">
</head>

<body>
<!-- cara satu -->
  Tuhan saya adalah : <?php echo $TUHAN ?>.
  <!-- cara dua -->
  Tuhan saya adalah : <?= $TUHAN ?>
</body>
</html>

```

jika dengan blade kita cukup gunakan tanda `{{}}`;

```blade.php

@php

$TUHAN = "ALLAH";
@endPhp;

<div>


tuhan saya adalah {{$TUHAN}}

</div>

```
