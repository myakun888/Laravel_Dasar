# Contorller

saat kita membuat route, kita juga harus membuat callback function , yang dapat kita isi code di dalam ny sesuai kebutuhan seperti , response, dan logic dari suatu code program.

```php

Rooute::get('/home', function () {

// ini kode program atau response nya
})
```

tapi perlu di ingat , saat kita membuat suatu logika pemrograman yang di campur di dalam route, ini kurang di sarankan. maka dari itu best practice nya kita harus pisahkan , inialah di sebut `Controller`.

jadi dengan kita memisakan atau memecah route tugas nya hanya untuk route, dan logic ada di Contorller.

controller secara default ada di path

```cmd
App/Http/Contorller
```

### membuat controller

membuat controller di laravel bisa dengan cara terminal `php artisan make:controller namaController`;
**contoh**

```cmd
php artisan make:PendudukController
```

maka otomatis file dengan nama `PendudukController.php ` akan di buat di path App/Http/controller
kurang lebih isi nya sebagai berikut.

### menulis function di dalam controller

lalu kita buat funciton, dalma contoh ini dengan nama `informasi`, di dalamnya bebas ktia buat logic seusai yang kita perlukan.

dan untuk satu controller boleh mememiliki lebih dari satu function, sesuai kebutuhan.

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class WargaController extends Controller
{
    // disini logica program bisa kita buat;

  public function informasi (){

    return " ini adalah informasi untuk warga";
  }


}
```

## menghubungkan controller dengan route

setelah kita membuat controller, kita dapat menghubungkan nya dengan rotue yang sudah pernah kita buat.

ini adalah format nya.

```cmd
Route::get('/path',[namaController::class,'function nya'])
```

berdasarkan controller contoh yang kita buat, maka untuk cara menghubungkannya dengan route, sebagai berikut.

```php
Route::get('/home',[WargaController::class, 'informasi']);
```

segala fitur seperti route parameter dan lainya tetap bisa di gunakan di controller.
contoh, pada route parameter

## menerima paarmeter dari route pada controller

sama saat di function callback di route cara nya mirip.

```php
Route::get('/home/{id}',[WargaController::class, 'informasi']);
```

```php


<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class WargaController extends Controller
{
    // disini logica program bisa kita buat;

  public function informasi ($id){

    return " ini adalah informasi untuk warga dengan $id";
  }
}
```
