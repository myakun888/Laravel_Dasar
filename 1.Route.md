# Route

adalah peta jalan yang di gunakan untuk menuju suatu halaman .
route atau dalam hal ini kita maksdu url nya,kita akan menentukan suatu route manu kemana dan tujuan nya apa.

### membuat route

```php


Route('url',fucntion(){
Return "Bismillah";
})
```

```php

Route('/salam', function (){
Return ("Bismillah");
})
```

lalu di browser nya, kita buat

```url
/salam
```

makan akan tampil "Bismillah";

## Route Paramter

kita juga bisa menuliskan / menambahkan parameter di suatu route jika memerlukan parameter
contoh

```php

Route('/data/{nama}',function($nama){

return asalamualaikum $nama;
})
```

contoh

```url

/data/fajrin

```

maka hasil nya adalah `asalamualaikum fajrin`.
perlu di ingat saat kita membuat parameter, maka wajib di isi jika tidak akan eror , atau 404

jika sebelumnya sudah di tulis seperti ini

```php

Route('/data/{nama}',function($nama){

return asalamualaikum $nama;
})
```

kalau kita buat

```url
/data/
```

ini akan error.

alternativ ktia bisa buat sebuah paremeter itu optional ini lebih aman

```php

Route('/data/{nama?}',function(?string $nama = null){

return asalamualaikum . $nama ?? "tuan".
})
```

> ket :
> parameter? , tanda ? dibelakang sebuah paremeter menandakan paremeter itu adalah optional.
> best practise nya , karena optional parameter itu mengembalikan null, maka di function nya kita beri juga tipe data lainya null boleh dengan ? didepan tipe data nya , dalam hal ini ?string, artinya tipe data parameter di function nya bisa untuk string dan null,
> lalu di paremeter nya kita kasih default value ny null,
> dan untuk isi nya kita bisa gunakan nullcoalisng operator dalam contoh di atasn $nama ?? "tuan". artinya jika nilai nama ada value atau nilai nya isi dengan niali tersebut, jika nilai nya null ganti dengan "tuan".

> > masih ada materi , mengenai route parameter yang lebih lanjut misalnya , paremeter binding , ini akan dibahas sambil jalan
