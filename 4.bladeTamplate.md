# Blade Tamplate

sebelumya kita sudah membahas View , pada materi laravel, di view laravel menggunkan tamplate dari blade.

Blade adalah mesin pembuat tamplate yang sangat cepat dan ringan di digunakan oleh laravel.

membuat file selalu di akhiri dengan `namafile.blade.php`

## menulis php di dalam blade

kelebihan pertama dari blade adalah kemudahan dalam menulis code php di dalam html nya, jika sebelumya kita harus membuat

menulis atau mencetak echo / print di php di dalam html

```php

<div>
<?php
echo "Assalamuaikum";
?>
</div>



```

dengan blade kita cukup

```blade.php

{{"Assalamuaikum"}}
```

sangat simple sekali, dan juga sudah mendukung _HTML entity escaping_ , untuk mencegah XSS (Cross-Site Scriping)

## directif code

dengan adanya directif code ini memudahkan kita menulis code program php di dalam laravel menggunkaan blade
jika ingin menulils kode php cukup dengan tanda

```blade.php

@php
$data = "ini code php";
@endphp

```

juga tersedia directif lain seperti

- @if , untuk if
- @forEach, untuk forEach
- @for, untuk for
- dan lainya

#### contoh

**directif forEach**

```blade.php

@php

$data = [10,11,12,90];

@endPhp



  @foreach ($nilai as $item)
     nilai nya adalah {{$item}} </br>;
  @endforeach

```

**directif For**

```blade.php

@php

$data = 0;

@endPhp

@for($data; $data < 10; $data++)

{{data}};
@endFor

```
