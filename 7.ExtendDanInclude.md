# Layout di Blade Tamplate

dalam menuli code di blade, juga menggunakan konsep layout, diantara nya adalah

- extend (),
- include (),
  dan juga directif seperti
- @section()
- @yield()
- @show

ini akan di bahas satu persatu.

## Extend

dengan adanya konsep layout memudahkan kita dalam menulis kode yang lebih modular, senhingga tidak menggulang menulis code yang sama untuk keperluan tertentu

extend artinya kita menggunakan suatu file dan mengambil semua perilaku / kode yang tertulis di dalam nya, ini biasya nya di gunakan dalam membuat code utama atau layout file .

`layoutUtama.blade.php`

```blade.php

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title></title>
    <link href="css/style.css" rel="stylesheet" />
  </head>
  <body>
    <h1>Assalamualaikum Selamat datang ini dari Layout Utama</h1>
  </body>
</html>


```

`index.blade.php`

```blade.php


include('layoutUtama');

ini dari index
```

maka isi dari file `layoutUtama` akan masuk ke dalam file `index.blade`

kita bisa menggunkan function ini untuk modular code yang biasa kita gunakan untuk memecah lebih kecil misal nya kita membuat komponent
contoh seperti
navbar,

#### apa perbedaan extend dan include

secara garis besar kita dapat asumsikan, jika extend artinya child mengambil / mengajak parent, sedangkan include, parent mengajakn child
